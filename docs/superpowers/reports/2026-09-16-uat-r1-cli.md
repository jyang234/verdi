## Contract implemented

- ac-1 (CLI part): `internal/buildinfo.Line()` derives module version +
  short (12-char) VCS revision + `modified` marker from
  `runtime/debug.ReadBuildInfo`, falling back to the honest placeholder
  `verdi (devel)` when build info is unavailable or version is empty —
  never fabricated. `verdi version` / `verdi --version` (version.go) print
  it to stdout, exit 0, dispatched as top-level tokens in `run()` before
  the verb-phase lookup (never added to `verbPhase`, so
  `internal/specalign`'s CLI-verb inventory is untouched). `verdi serve`
  prints the identical line once, as its first stdout line, before the
  existing MCP-socket/workbench lines (serve.go).
- ac-2: central intercept in `dispatch.go`'s `run()`. `help`/`--help`/`-h`
  at top level print a new, richer `topLevelUsage` (one line per verb with
  a short description) to stdout, exit 0 — the existing compact `usage`
  const is untouched (still the no-args/unknown-verb stderr/exit-2 path,
  co-2). The same three tokens immediately after any known verb print that
  verb's `verbUsage` registry entry (one line per subverb/form) to stdout,
  exit 0, *before* the verb's real function is ever called — fixing both
  named defects: `verdi lint --help` no longer runs a lint, and
  `verdi spec --help` is now the clean stdout/exit-0 path instead of the
  usage-error stderr/exit-2 path. `designVerbUsage` was reformatted
  in-place to multi-line (contract-permitted); all 11 forms preserved
  byte-for-byte, only " | " became newlines. Every other `verbUsage`
  entry reuses an existing ratified constant (`obligationVerbUsage`,
  `waiveUsage`, `experimentUsage`) or is a fresh literal grounded in that
  verb's real argument-shape check.

Review-fix additions to the same contract: `verbUsage["help"]`/`["version"]`
plus matching branches in `dispatch.go` so "verdi version --help" and
"verdi help help" (and every three-spelling combination of each) show
that row's own usage rather than the version report or a second
top-level dump; `designVerbUsage` gained the real `--from-stub <feature>
<stub>` form it had omitted; `verbUsage["disposition"]` is now a clean,
hand-written `usage: verdi disposition ...` line instead of reusing
`dispositionUsage`/`dispositionRecordUsage` verbatim (those two error-
prefixed constants are untouched at their own real call sites); and
`TestVerbUsageRegistry_CoversEveryVerb` (help_test.go) now guards every
`verbPhase` key plus `"lint"` against a future silent gap.
